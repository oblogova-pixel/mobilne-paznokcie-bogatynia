# Mobilne paznokcie • Bogatynia

Strona mobilnego manicure i pedicure w Bogatyni i okolicy (do 10 km).

## Uruchomienie

Strona statyczna, bez instalacji zależności. Uruchom w katalogu repozytorium:

```sh
python3 -m http.server 8000
```

Otwórz http://localhost:8000.

## Pliki

- `index.html` — treść strony, cennik i 40 prac w portfolio
- `style.css` — wygląd i wersja mobilna
- `app.js` — formularz, galeria oraz informacja o cookies
- `assets/` — zdjęcia, tła, logo i favicon

Formularz zapisu jest demonstracyjny i nie wysyła zgłoszeń. Integracja z Telegramem pozostaje do wdrożenia. Przyciski telefonu i linki do mediów społecznościowych działają.
